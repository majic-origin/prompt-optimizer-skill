# 六模块成品模板

五类场景的成品骨架。照抄结构，替换具体内容，删掉用不上的模块。

每个模板末尾的"待确认"行留给阶段的缺口处理。

## 代码任务

```markdown
## 目标
实现 {{功能}}，使 {{现有系统}} 具备 {{能力}}，产出可直接运行并通过验收的代码。

## 背景
- 技术栈：{{语言}} + {{框架}} + {{版本}}
- 运行环境：{{本地 / 容器 / 已有服务}}
- 现有代码：{{路径}}，{{可改 / 只能新增}}
- 已有依赖：{{列出，不新增}}

## 关键约束
- 不引入新依赖
- 命名用英文，注释用中文
- 不改动 {{文件}} 之外的既有逻辑
- 禁止：{{禁止项}}

## 执行步骤
1. 读 {{路径}}，确认现有接口与数据结构
2. 写出实现，覆盖 {{边界情况}}
3. 补测试，覆盖 {{正常路径}} 与 {{异常路径}}
4. 跑一遍，贴出执行结果

## 输出格式
1. 变更文件清单，每项一句话说明改动
2. 完整代码，按文件分块
3. 运行命令与实测输出
4. 未能验证的部分

## 验收标准
- 编译或启动无报错
- {{测试命令}} 全部通过
- 新增代码不修改既有函数签名
- 每个边界情况都有对应测试
```

## 写作任务

```markdown
## 目标
写一篇 {{体裁}}，主题 {{主题}}，面向 {{受众}}，产出 {{字数}} 的成稿。

## 背景
- 已有材料：{{列出，没有就写"无"}}
- 发布渠道：{{渠道}}
- 参考风格：{{参考对象或风格描述}}

## 关键约束
- 篇幅 {{字数}}，上下浮动不超过 10%
- 视角 {{第一人称 / 第三人称}}
- 不用 {{风格禁区}}
- 禁止：编造未提供的数据、案例、引语

## 执行步骤
1. 先确认核心观点，一句话
2. 列结构，逐节写小标题
3. 按结构成文
4. 复查是否有编造内容

## 输出格式
Markdown。标题层级两级以内，正文分段，不长段堆叠。

## 验收标准
- 核心观点在开头 200 字内出现
- 每个数据或案例都能指出来源
- 没有未提供的人物、机构、数字
- 字数落在要求区间
```

## 分析任务

```markdown
## 目标
分析 {{对象}}，回答 {{具体问题}}，产出结论与依据。

## 背景
- 材料来源：{{用户提供的文件 / 需要外部检索}}
- 分析目的：{{拿结论去做什么决定}}
- 已有判断：{{用户已有的倾向，如有}}

## 关键约束
- 依据只来自 {{材料来源}}
- 结论强度到 {{建议 / 结论 / 可能性列举}} 为止
- 未知项写明未知，不补
- 禁止：把推测写成陈述

## 执行步骤
1. 读材料，列出与问题直接相关的条目
2. 逐条给出支撑或反驳
3. 汇总结论，标出不确定项
4. 列出还需要什么材料才能提高确定性

## 输出格式
结论先行，随后依据。依据逐条对应材料出处。

## 验收标准
- 每个结论都能指到材料的具体位置
- 推测与已核实分开标注
- 未回答的问题明确列出
```

## 数据任务

```markdown
## 目标
基于 {{数据来源}}，算出 {{指标}}，产出 {{表格 / 图表 / 解读}}。

## 背景
- 数据位置：{{路径或来源}}
- 时间范围：{{范围}}
- 样本范围：{{纳入与排除规则}}

## 关键约束
- 口径：{{单位、是否去重、时区}}
- 缺失值处理：{{显式标注 / 排除}}，不做插值
- 保留原始数据不动，产出另存
- 禁止：用估算值填补缺失

## 执行步骤
1. 读取并核对行数、字段、时间范围
2. 按口径计算
3. 交叉验证一遍，说明验证方式
4. 输出结果与口径说明

## 输出格式
结果表在前，口径说明在后。表头含单位。

## 验收标准
- 结果可复现，命令或脚本一并给出
- 口径说明覆盖时间、样本、单位、去重规则
- 缺失与异常单独列出条数
```

## 设计任务

```markdown
## 目标
产出 {{设计物}}，用于 {{场景}}，交付 {{格式与尺寸}}。

## 背景
- 平台与尺寸：{{尺寸}}
- 参考对象：{{参考}}
- 必须包含：{{标题、署名、标识等}}

## 关键约束
- 主色 {{色系}}，配色不超过三种
- 字体使用系统可用字体
- 元素间距不小于 {{值}}
- 禁止：{{禁止项}}

## 执行步骤
1. 确认信息层级，排出主次
2. 定版式骨架
3. 填内容与装饰
4. 检查对比度与可读性

## 输出格式
{{文件格式}}，附一份设计说明，写明每项取舍的理由。

## 验收标准
- 标题在缩略图尺寸下仍可辨认
- 对比度满足可读要求
- 必需元素齐全
- 尺寸与平台要求一致
```
