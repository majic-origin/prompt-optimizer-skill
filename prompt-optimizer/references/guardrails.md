# 防幻觉约束

下面这段可以整段复制进提示词末尾。按需删减，不要改措辞里的判定强度。

## 标准约束块

```text
事实纪律：

1. 每个数字、日期、引用、链接都要能指出来源。指不出来就写"此处无来源，需要核实"，并给出核实方向。
2. 你的表述按三级标注：
   - 已核实：附来源
   - 推测：前缀"推测"，并写出推断依据的链条
   - 未知：直接说明没有依据
3. 不添加我没写的信息。人物、机构、地名、金额、时间顺序、因果关系、动机，我没说的一律不补。
4. 不放大判断强度。我说的"可能""通常""据说"保持原样。
5. 不确定时明说不确定，不用看起来像结论的措辞糊过去。
6. 我的材料与你的训练知识冲突时，以我的材料为准，并指出冲突点。
```

## 三级标注的判据

| 级别 | 判据 | 允许的写法 |
|---|---|---|
| 已核实 | 用户提供了来源，或本次对话中读取到了原文 | 直接陈述，附路径或链接 |
| 推测 | 由已核实信息推断，逻辑链可复述 | "推测：" 加依据链 |
| 未知 | 无来源，凭印象或常识 | 明说没有依据 |

一条表述归入哪级，看的是来源，不是把握大小。感觉很有把握但没有来源，仍然归未知。

## 常被编造的位置

这六处最容易出现凭空填充，写进提示词时要额外点明：

- 数字与比例。用户说"增长很快"，不能变成"增长了 37%"
- 时间与顺序。用户没说先后，不能替它排因果
- 人物、机构、地名。用户说"我们团队"，不能变成"由三人组成的团队"
- 引用与出处。任何链接、文献、名言，必须来自用户材料或本次检索
- 因果与动机。用户说"结果变了"，不能解释成"因为改了流程"
- 场景与细节。用户没给的时间和地点，不能补齐

## 强度守恒

改写或总结时，原话的限定词必须保住。对照表：

| 原话 | 保住 | 不写成 |
|---|---|---|
| 可能提升 | 可能提升 | 提升了 |
| 通常在三天内 | 通常 | 三天内 |
| 据说他拒绝了 | 据说 | 他拒绝了 |
| 部分模块支持 | 部分 | 全部支持 |
| 初步看效果不错 | 初步 | 效果显著 |

把"可能"改成"就是"，属于篡改，不属于优化。

## 无法核实时的标准写法

核实不了，给三个方向，不给替代品：

```text
这一项我没有依据，无法给出数字。要确认的话有三个方向：
一是查 XX 官方文档的 XX 章节；
二是问你司内部负责 XX 的同事；
三是说明来源后我帮你核对。
```

不给"大约""大概""估计在 X 左右"这类填充。估算必须标明是估算，并说清估算依据。

## 检索与引用

- 需要外部信息时先检索，再写。检索不到就写检索不到，并给出检索词
- 引用格式统一为链接或路径。不写"有研究表明"这种无主体来源
- 引用内容与原意不符时以原文为准，允许改写措辞但必须保住原意

## 与用户材料冲突

用户的材料优先于训练知识。冲突时写出两边的说法，标出冲突点，让用户判断。

不要因为训练知识更"标准"就覆盖用户给的材料。用户的材料是他现场的事实，训练知识是过时的普遍印象。

## 自检

输出前过一遍：

- 每个数字能不能指出出处
- 有没有把推测写成了陈述
- 有没有添加用户没给的人物、时间、因果
- 原来的限定词还在不在
- 有没有出现"有研究表明"这类无主体来源
- 与用户材料冲突的地方有没有显式标出
